ENHANCED BIRTHDAY SURPRISE WEBSITE

Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a browser, or upload the folder contents to GitHub Pages / Netlify / Vercel.
3. Personalise names and messages in script.js and index.html.
4. Add your photos to an images folder using these filenames:
   first-memory.jpg, favourite-day.jpg, best-smile.jpg
   (The page shows a friendly fallback if those photos are missing.)

Note: Google Fonts and the original hero image use internet resources. Replace the hero image URL with a personal photo for the best result.
